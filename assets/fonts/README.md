# Latin Modern

Police par défaut de LaTeX moderne (successeur de Computer Modern), utilisée
ici pour le corps de texte et les titres.

Fichiers `.woff2` repris du paquet npm [`latex.css`](https://latex.vercel.app)
(v1.14.0). La police elle-même est publiée par le GUST e-foundry sous **GUST
Font License**, qui autorise la redistribution :
<https://www.gust.org.pl/projects/e-foundry/licenses>

Ils sont hébergés dans le dépôt plutôt que chargés depuis un CDN : le site
reste autonome, s'affiche correctement hors ligne, et aucune requête n'est
envoyée à un tiers quand quelqu'un visite la page.
